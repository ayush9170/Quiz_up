🧠 Real-Time Multiplayer AI Quiz App

A web app that lets users log in with Google, generate quizzes using GPT-4, and play them in real time with friends.

✨ Features

1. Google Auth for easy login

2. AI-Generated Quizzes powered by GPT-4

3. Create Multiplayer Rooms and compete live

4. Real-Time Sync using Pusher channels

5. Simple and clean UI styled with Tailwind CSS

6. Database layer managed with Prisma + MongoDB

🛠️ Tech Stack <br>
Frontend:	Next.js, Tailwind CSS <br>
Backend:	Node.js, Next.js API Routes <br>
Auth:	Google OAuth (NextAuth or custom) <br>
Database:	MongoDB + Prisma ORM <br>
Real-Time Updates:	Pusher <br>
AI:	GPT-4 API
